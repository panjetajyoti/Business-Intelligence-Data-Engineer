An enterprise-grade repository documenting the end-to-end lifecycle of Business Intelligence and Data Engineering. This capstone portfolio spans foundational theoretical architecture, multi-national retail data warehousing (ETL/Star Schema), e-commerce transactional modeling with index-driven SQL optimization, and healthcare clinical/operational KPI dashboard visualization.
